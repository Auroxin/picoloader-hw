# picoloader v1.1 — discontinued

First published revision of the main board. It was superseded by [v1.1A](../v1.1A) and then
[v1.2A](../v1.2A), and is kept in the repository for design history only — it is **not**
manufactured any more.

* 27.21 × 36.04 mm, 37 footprints
* SPI flash `ZD25WQ16CEIGR` (2 MB), USON-8 3×2 mm
* every footprint drawn in this project's own `Library.pretty`

Open `picoloader.kicad_pro` with KiCad 10 or newer.
